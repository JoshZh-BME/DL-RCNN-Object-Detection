RCNN objektumdetektálás — lépésről lépésre magyarázat
=====================================================

A notebook a klasszikus RCNN (Girshick et al., 2014) algoritmust valósítja meg.
Az alapötlet: régiókat generálunk a képen, minden régióból CNN feature-t
nyerünk ki, majd SVM-mel osztályozunk. Nézzük végig a 8 szekciót.

2. RCNN háló létrehozása (cell-8, cell-9, cell-10)
----------------------------------------------------

Az RCNN három fő komponensből áll:

2a. FeatureExtractor — ResNet50 backbone

  resnet = models.resnet50(weights=ResNet50_Weights.IMAGENET1K_V1)
  self.features = nn.Sequential(*list(resnet.children())[:-2])
  self.avgpool = nn.AdaptiveAvgPool2d((1, 1))

  Miért vágjuk le az utolsó rétegeket? A teljes ResNet50:
    [conv layers ...] → [avgpool] → [fc (1000 osztály)]
                                        ↑ itt vágunk le

  A levágás után egy 2048 dimenziós feature vektort kapunk minden
  képrégióból. Ez egy tömör, szemantikus leírása a régió tartalmának —
  az ImageNet előtanítás miatt már "érti" a vizuális fogalmakat.

  A forward():
    bemenet (batch x 3 x 224 x 224)
      → conv rétegek → feature map
      → AdaptiveAvgPool2d((1,1)) → 2048 elemű vektor

2b. Képtranszformáció

  transform = T.Compose([
      T.Resize((224, 224)),                     # ResNet fix bemeneti méret
      T.ToTensor(),                             # PIL → tenzor [0,1]
      T.Normalize(mean=[0.485,0.456,0.406],     # ImageNet normalizálás
                  std =[0.229,0.224,0.225])
  ])

2c. extract_region_features() — a feature kinyerés motorja

  Ez a függvény végzi a tényleges munkát:

  Bemenet: PIL image + régiók listája [(x,y,w,h), ...]
    1. Minden régiót kivág az eredeti képből: image.crop((x, y, x+w, y+h))
    2. Átméretezi 224×224-re, normalizál
    3. Batch-be rendezi (64 régió egyszerre)
    4. Végigfuttatja a ResNet50-en
    5. Összegyűjti a 2048 dimenziós feature vektorokat
  Kimenet: numpy tömb (N_régió x 2048)

2d. Az RCNN osztály — három gépet tanít be:

  | Komponens             | Típus                  | Szerepe                              |
  |-----------------------|------------------------|--------------------------------------|
  | svm_classifiers[20]   | LinearSVC osztályonként| Eldönti, milyen objektum van         |
  | ridge_regressors[20]  | Ridge regresszió       | Finomítja a régiókoordinátákat       |
  | scaler                | StandardScaler         | Feature-ök standardizálása           |

  fit_svm() — one-vs-rest stratégia:
    Minden osztályra (0..19):
      y = (labels == cls_idx) → True/False → 1/0
      Ha van pozitív minta: LinearSVC.fit(features, y)
    A LinearSVC(C=0.1, max_iter=5000) egy lineáris SVM.
    A C=0.1 erős regularizációt jelent.

  fit_regressors() — bbox finomítás tanítása:
    Minden osztályra, ahol >=10 minta van:
      A regressziós célértékek (tx, ty, tw, th):
        tx = (gt_x - prop_x) / prop_w     # x irányú eltolás normalizálva
        ty = (gt_y - prop_y) / prop_h     # y irányú eltolás normalizálva
        tw = log(gt_w / prop_w)           # szélesség skálázás log-térben
        th = log(gt_h / prop_h)           # magasság skálázás log-térben
    A log-tér használata azért fontos, mert a szélesség/magasság
    arányok eloszlása log-normális.

  predict() — predikció új képen:
    1. Feature kinyerés minden régióra
    2. StandardScaler.transform()
    3. Minden osztályra: SVM decision_function() → konfidencia score-ok
    4. Ha van regresszor: delták predikciója → bbox koordináták
       visszaalakítása:
         cx = x + w/2 + tx*w,  cy = y + h/2 + ty*h
         new_w = w * exp(tw),  new_h = h * exp(th)


3. Adatelőkészítés (cell-12, cell-13)
--------------------------------------

3a. compute_iou() — Intersection over Union

  Az IoU azt méri, mennyire fed át két téglalap:
    IoU = metszet_területe / unió_területe
  Ha IoU = 1.0 → tökéletes egyezés, IoU = 0.0 → nincs átfedés.
  Ez az objektumdetektálás alapvető metrikája.

3b. get_selective_search_regions() — régió javaslatok

  A Selective Search egy klasszikus (nem tanuló) algoritmus, ami kép
  szegmentáción alapul:
    1. Túl-szegmentálja a képet (sok kis régióra bontja)
    2. Hasonló szomszédos régiókat iteratívan összevon
       (szín, textúra, méret alapján)
    3. Minden összevonásnál az új régiót elmenti mint régió javaslatot

  Beállítások:
    • switchToSelectiveSearchFast() — gyorsabb, de kevésbé alapos
    • Csak 20px-nél nagyobb és a kép 90%-ánál kisebb régiók maradnak
    • Alapból max 500 régiót generál képenként

3c. prepare_training_data() — tanítóadatok generálása

  Minden képre:
    1. Betöltjük a képet és az XML annotációt (ground truth)
    2. Selective Search → régió javaslatok
    3. Minden régióból ResNet50 feature kinyerés
    4. Minden régióra megkeressük a legjobb IoU-jú ground truth objektumot
    5. Címkézés:
       - IoU >= iou_pos (0.5) → POZITÍV minta: feature + osztály_címke + gt_bbox
       - IoU < iou_neg (0.3)  → NEGATÍV minta (háttér): feature + címke=-1
       - 0.3 <= IoU < 0.5     → KIDOBJUK (túl bizonytalan)

  A kettős küszöb (0.5 és 0.3) lényege: a bizonytalan régiókat (amik félig
  fednek át egy objektummal) nem használjuk, mert összezavarnák az osztályozót.


4. Tanítás és kiértékelés (cell-15 → cell-19)
----------------------------------------------

4a. Tanítás

  200 train kép, képenként max 200 régió → kb. 40 000 régió feldolgozása.

  Tanítási folyamat:
    prepare_training_data() → train_features (N x 2048), train_labels (N)
      ↓
    rcnn.fit_svm(train_features, train_labels)
      → Mind a 20 osztályra: StandardScaler + LinearSVC one-vs-rest
      ↓
    rcnn.fit_regressors(pozitív_minták)
      → Minden osztályra (ahol >=10 minta): Ridge regresszió

4b. Kiértékelés — mAP számítás

  A mean Average Precision (mAP) az objektumdetektálás standard metrikája.

  1. lépés — Detekciók gyűjtése:
    Minden validációs képre:
      → 100 régió generálása Selective Search-csel
      → Minden régióra predikció (osztály + score)
      → Top-20 detekció megtartása osztályonként

  2. lépés — Precision-Recall görbe osztályonként:
    Detekciók rendezése score szerint csökkenőbe
    Minden detekcióra:
      Ha a legjobb IoU >= 0.5 valamelyik még nem használt GT-vel
        → True Positive
      Különben → False Positive

    TP_cum = kumulatív TP
    FP_cum = kumulatív FP
    Recall = TP_cum / összes_GT
    Precision = TP_cum / (TP_cum + FP_cum)

  3. lépés — Average Precision 11-pontos interpolációval:
    for t in [0.0, 0.1, 0.2, ..., 1.0]:  # 11 recall szint
        AP += max(precision ahol recall >= t)
    AP /= 11

  4. lépés — mAP:
    mAP = átlag(AP_repülő, AP_bicikli, ..., AP_tv)

  A cell-19 vizualizálja a per-class AP értékeket
  (zöld: >0.1, narancs: >0.05, piros: gyenge).


5. Hiperparaméter optimalizálás (cell-21, cell-22)
---------------------------------------------------

5a. IoU küszöb hangolás

  Három különböző IoU pozitív küszöbbel tanít:
    • IoU=0.4: több pozitív minta, de zajosabbak
    • IoU=0.5: kiegyensúlyozott (alapértelmezett)
    • IoU=0.6: kevesebb, de pontosabb pozitív minta

  50 train + 20 val képen összehasonlítva.
  Trade-off: több minta → jobb SVM, de pontatlanabb bbox regresszió.

5b. ResNet18 vs ResNet50

  Két backbone architektúra összehasonlítása:

  | Tulajdonság       | ResNet18 | ResNet50 |
  |-------------------|----------|----------|
  | Feature dimenzió  | 512      | 2048     |
  | Rétegek száma     | 18       | 50       |
  | Sebesség          | gyorsabb | lassabb  |
  | Pontosság         | alacsony | magasabb |

  Mindkettő ImageNet előtanított.

A TELJES PIPELINE ÁTTEKINTÉSE
------------------------------

Tanítási fázis:
  Pascal VOC képek → Selective Search régiók → ResNet50 feature kinyerés
  → 2048 dimenziós feature vektorok → IoU alapú címkézés (±)
  → LinearSVM osztályonként + Ridge regresszió osztályonként

Predikciós fázis:
  Új kép → SS régiók → ResNet50 features → SVM score + bbox refine

Ez a klasszikus RCNN architektúra. A modern megoldások (Fast RCNN,
Faster RCNN, YOLO) ezt fejlesztik tovább azzal, hogy a régiógenerálást
és a feature kinyerést egyetlen neurális hálóba integrálják,
drasztikusan gyorsítva a futási időt.
